Kiến Trúc Web Tĩnh (Static Web Architecture)

🌐 Hoạt Động 100% Độc Lập Trên Web Tĩnh:

  • Không cần máy chủ (Zero Server): Chạy mượt mà trên GitHub Pages, Netlify, Vercel, Acode Android, hoặc mở trực tiếp file index.html (giao thức file:///).
  • Phát giọng đọc Offline: Sử dụng Web Speech API tích hợp sẵn trong trình duyệt để đọc to từng câu phụ đề theo thời gian thực mà không tốn băng thông.
  • Mã hóa MP3 tại chỗ (Client-Side MP3): Thư viện lamejs nén file MP3 trực tiếp trong bộ nhớ trình duyệt, căn chuẩn từng mili-giây theo mốc thời gian VTT/SRT.
  • Bảo mật tuyệt đối: Nội dung kịch bản và phụ đề không bị tải lên bất kỳ máy chủ bên thứ ba nào.

⚡ Khi Kết Nối Máy Chủ Nâng Cao:

Khi có backend Node.js (như Cloud Run), hệ thống tự động kích hoạt thêm engine Microsoft Edge TTS chất lượng cao (giọng đọc nơ-ron Hoài My & Nam Minh).
